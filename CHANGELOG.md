## [21.1.0.20] — 2026-09-30

### Изменено
- Нейтральный tagline: `DPI console · VPN Split`
- Подсказки на Control / VPN Split / Telegram — проще, без лишнего жаргона (детали в tooltip)
- VPN Split: пустой список с понятным CTA; статусы туннеля и кнопки переименованы понятнее
- Telegram: в остановленном состоянии подсказка «Запустить → Открыть»
- Первый запуск: баннер «3 шага» (DPI → VPN Split → Telegram) вместо выбора пресета
- VPN Split после «Применить»: явный статус конфига / маршрутов Telegram / туннеля
- Control: кнопка «Запустить» крупнее вторичных Stop / Выход
- HUD `// SECTION` mono-заголовки на VPN Split и Telegram; плотнее отступы страниц (12–14px)
- Единый phosphor PulsingDot: Control / VPN Split / Telegram (ok / idle / err)
- MessageBox: FluentIcon + выравнивание иконок (как в диалоге закрытия); danger для удаления
- Светлая тема: выше контраст текста; в UI явно «Тёмный (рекомендуется)»
- README: секция скриншотов + чеклист в `docs/screenshots/`
- Perf (безопасно): таймеры VPN/TG только на видимой странице; PulsingDot 140ms и стоп в трее; общий кэш DPI/туннель 1.5с; Logs не греются на старте; spinner ~30 FPS

### Исправлено
- «О программе»: скрыт блок лицензии (`HIDE_LICENSE_UI`)
- «О программе»: нормальное описание RKNHS, возможности, подсказка про AmneziaWG и контакт Telegram
- Диалог закрытия: иконки на кнопках больше не съезжают относительно текста (FluentIcon + выравнивание)

## [21.1.0.19] — 2026-09-30

Первый публичный релиз форка **RKNHS** (портфолио / личная модификация).

### Добавлено
- Брендинг **RKNHS**, тёмная tech-UI тема (`DESIGN.md`)
- **VPN Split**: домены и wildcards (`*.cursor.sh`), резолв IP → AmneziaWG `AllowedIPs`, DPI-исключения (`ipset-vpn`)
- Массовое удаление доменов в VPN Split (мультивыбор, Del, «Очистить весь список»)
- Импорт списка доменов (вставка / `.txt`)
- Установщик **Inno Setup** с обновлением поверх старой версии (личные `settings` не затираются)
- Сценарии пресетов, карта трафика, дашборд сервисов
- Трей: старт/стоп и переключение без окна
- Лицензионный gate (опционально)
- ISP auto-preset на холодном старте
- Документация: README с требованиями (AmneziaWG для VPN Split), контакты

### Исправлено
- Парсер AmneziaWG `.conf`: UTF-8 BOM больше не выкидывает секцию `[Interface]`
- Переустановка CLI-туннеля по **имени** туннеля (маршруты реально обновляются)
- Защита от использования `active.conf` как исходного конфига
- Стабильнее сосуществование DPI и VPN Split для Telegram (CIDR в `AllowedIPs`)

### Важно для пользователей
- Обычный DPI работает **без** AmneziaWG
- **VPN Split** требует установленный **AmneziaWG** и свой `.conf`
- Личные VPN-ключи в установщик и публичный репозиторий **не входят**
