# Screenshots checklist

Папка для портфолио-кадров RKNHS. Добавляйте PNG/WebP (~1280–1600px по ширине), тёмный режим.

## Имена файлов

| Файл | Кадр |
| --- | --- |
| `01-control.png` | Главная: статус + «Запустить» |
| `02-vpn-split.png` | VPN Split со списком сайтов или empty state |
| `03-telegram.png` | Telegram Proxy (остановлен с CTA или работает) |
| `04-about.png` | «О программе» |

После добавления файлов вставьте их в `README.md` секцию «Скриншоты»:

```markdown
![Control](docs/screenshots/01-control.png)
```
